# گزارش آموزش و کالیبراسیون شروط آفرهای سکه — ۲۰۲۶-۰۸-۲۰

## حکم

دور پژوهشی اولیه روی silver labelها و کالیبراسیون ماشینی آن کامل شده؛ این کار
آموزش نهایی یا owner-ground-truth محسوب نمی‌شود و نتیجه هنوز
`OWNER_REVIEW_REQUIRED_NOT_PROMOTED` است. هیچ مدل runtime، تلرانس قیمت، staging یا
production تغییر نکرده است. کاندید پیشنهادی، مدل کلاسیکِ hashed-feature با
کالیبراسیون Platt و ناحیهٔ abstain است. encoder فارسی به‌عنوان challenger آفلاین
نگه داشته می‌شود. بنا بر تصمیم مالک، چرخهٔ آموزش بعدی و full fine-tune فعلاً آغاز نمی‌شود؛
مدل و صفحه فقط برای shadow و برچس‌گذاری آینده حفظ می‌شوند.

## کالیبراسیون

برای هر head، مدل فقط روی train fit شده است. روی calibration، Platt scaling با
پیش‌بینی out-of-fold پنج‌تایی انجام شده؛ آستانهٔ مثبت و منفی مشترکاً انتخاب شده‌اند
و دست‌کم ۰٫۱۰ فاصلهٔ abstain دارند. sealed evaluation در fit، calibration یا
انتخاب threshold استفاده نشده است. در cross-group نیز threshold فقط از گروه مبدأ

## مقایسهٔ مدل‌ها

- کلاسیک: macro F1=۰٫۷۹۱؛ پنج head از هفت head آموزش‌پذیر gate را پاس کردند؛
  CPU p50=۲٫۸۱۳ms و p95=۳٫۰۹۶ms برای هفت head.
- encoder منجمد فارسی: macro F1=۰٫۷۵۲؛ پنج head gate را پاس کردند؛ CPU
  p50 حدود ۳۴۷ms. در `PAYMENT_ACCOUNT` اختلاف F1 اندکی به سود neural بود
  (۰٫۹۵۱ در برابر ۰٫۹۴۸)، ولی هزینهٔ CPU و نتایج سایر فیلدها انتخاب آن را توجیه
  نمی‌کند.
- cross-group کلاسیک برای تشخیص کلی شرط: گروه۱→۲ F1=۰٫۹۲۱ و گروه۲→۱
  F1=۰٫۹۵۶. اختلاف خانواده‌های جزئی نشان می‌دهد threshold مشترک runtime هنوز
  بدون truth set مالک مجاز نیست.

## محدودیت قطعی

اعداد بالا کیفیت بازتولید silver labels را می‌سنجند، نه صحت نهایی اقتصادی/زبانی.
تا ارزیابی مالک، خانواده‌های مسدود تصمیم ماشینی ندارند، full fine-tune انجام
نمی‌شود و هیچ خروجی این پژوهش نباید به tolerance یا مسیر ثبت آفر وصل شود.
