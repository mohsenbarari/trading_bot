# Preferences

- متن‌های فارسیِ محصول، به‌ویژه آموزش و خطا، باید تا حد امکان کوتاه و عملی باشند و فقط اطلاعات لازم برای اقدام درست کاربر را نگه دارند؛ از توضیح فنی، تکرار و جزئیات غیرضروری پرهیز شود.
- در Review پلن، تمام موارد باز سناریومحور و شامل وضعیت اولیه، رخداد، رفتار مورد انتظار، مانع ایمنی و تصمیم لازم باشند؛ فهرست انتزاعی به‌تنهایی کافی نیست.

- در اتوماسیون، پیشرفت واقعی ریفکتور، کیفیت و کاهش خطا/توقف بر صرفه‌جویی توکن مقدم‌اند؛ بهینه‌سازی مانع تحویل باید ساده یا حذف شود.
