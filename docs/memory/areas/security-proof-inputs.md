# Security proof inputs

For source/FD APIs also load `security-io-custody.md`.
- Size actual FD/source/cgroup namespaces; predictions/PIDs prove no HOST/cost.
  Fix measured windows; never extend scans. OWNED LIVE may skip sizing, never
  bounded census. Failed sizing needs a fresh scope without relabeling.
- Scanner loans outlive proc reads/physical closes. Retirement/failure stay separate from telemetry; profiles/exits never heal errors. After source close, final checks open no proc loans; failed-only disposal stays usable.
- DATA proves no operation. Pilot actual constructors/generated code; bind
  receivers/globals/closures. Mutate private test copies only.
- ELF joins bind path/hash/owner/variant/sections/symbols; byte coverage proves
  no control flow. TEST/CMP do not write registers. Review decoded bodies and
  metadata with matching LTO tools. Imports/old Python prove no LTO closure;
  current bodies prove no historical flags or future link.
- Static `.a` may be GNU ar, ET_REL or linker script. Keep NOTYPE data sizes;
  symbol-free objects require absent symbol/relocation tables and exact meaningful
  section bytes. Function sizes alone do not define ABI.
- Wheel identity binds RECORD paths/hashes/sizes, DSOs and source/build originals.
  Empty markers admit no empty ELF; labels/placeholders prove no SOURCE.
- Group exit needs original pidfd and task/proc absence; wait for reaping within the original deadline. Keep thread birth/holder custody and source exit/proc-container proofs. Leader Z/UID0 cannot erase holders. Test UID/thread changes without global PID/TID-set equality.
- FIRST-stat ENOENT then foreign FD reappearance is fresh bounded work; closure needs two proven absences. Known-target drift is fatal.
- Failed-only disposal accounts for retained Pair prefixes before releasing context fences. Unknown close keeps fences; known closure never heals errors.
- Profile-bound business directories need stable5 at preparation CAS, initial/repeated Core and G FD checks. Namespace size/link counts/timestamps are mutable, not identity. Keep regular/model/credential/fence/generic-parent contracts strict.
- After finalizers, recheck names and original client/request/decision/global deadlines without retired callbacks; retain errors. Only proven post-last-close namespaces use exact stable7 plus nondecreasing times; held namespace FDs and regular files keep full9.
- Bind exact name/version/Epoch/BinNMU/arch; signed Source-Version may differ.
  One-row queries are insufficient. Keep duplicates; metadata proves no product
  hashes, signatures, installed ELF equivalence or siblings.
- Reject failed/closed forward scopes before acquisition/mutation. Failed cleanup needs separate typed authority, never healthy guards. Latch errors.
- Cache metadata only within one guarded pass; preserve OFDs/flags/failure
  finality. Guard spawns, finalizers and I/O, including exceptions; retain
  primary/postcheck errors.
