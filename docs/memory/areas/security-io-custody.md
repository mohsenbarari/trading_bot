# Security I/O and custody

- QA: preflight HOST/entry, roles/schemas/APIs/types/counts/modes/fixtures/bounds/DAG. Refresh/retain inherited assertions; templates grant nothing. Keep limits/siblings/driver __file__. Survey roles before exceptions; test extracted helpers' globals/calls. Bound B.run logs first; bounded pread/hash for .raw. Scoped patches preserve context; GNU patch before CI. Freeze modes and inputs/receipts. Profilers precompute filenames/code, never per-call pathlib/I/O.
- Typed modes: Root sources0644, receipts0600/0644, UID10001 build sources,
  private controls0600. Preserve borrowed owners/modes. Open mode obeys umask;
  fchmod only a qualified new owned FD. Test actual umask077 and UID/GID.
- Hold bounded responses in RAM through collector close. Bind original streaming
  writer full9/bytes/hash before selector/pipe closure; check the retained reader
  across writer close. Publish immutable bytes afterward; known bytes never
  justify inode/metadata replacement.
- Pipe/FIFO writes naturally change mtime/ctime. Bind original dev/inode/mode/uid/gid/
  nlink/size and fd flags, plus exact stream length/hash/EOF; timestamps are
  observations. Keep every regular-file full9 guard unchanged.
- Map refusal codes; keep unknown operands private. Keep physical-finalizer
  and earlier errors; prioritize finalizer. Closure requires current original
  closes/final names; prior success/JSON/timing proves none. Budget guards/hashing
  within original deadline.
- Test prefixes through failed cleanup, beyond raises/AST. Keep
  first errors and initialized guards. New typed roles need latched checks/close,
  EBADF and complete original-or-HELD accounting; legacy close/flags prove none.
- Source sealing: clean Main/registered temporary checkout, intact branch checks,
  host interpreter. Use full9, never whole os.stat_result/atime.
- Report-writing verifiers use fresh packet copies. Separate author/Root
  receipts; preserve frozen QA metadata.
- S.Reader.raw_binding is None without a pin. Supply the exact pin or guarded hash. Test actual admission before payload/spawn, beyond stubs.
- Operations need bounded durable sanitized status before entry. Lost output proves neither closure nor retry eligibility; retain UNKNOWN.
- Test acquisition prefixes, FD/flag drift, same-inode reopen even at offset0, restoration, no-op close and non-EBADF final-stat. Lock custody needs original OFD and current own-lock proof; re-locking can heal a lost lock. Latch close-entry and close failures across check/named. Uncertain ownership stays HELD; fixture disposal is separate evidence.
- Capture original receivers, FD aliases, witness/metadata registries. Mutable aliases cannot decide owned-FD existence. Deduplicate metadata reads, never bindings. Incomplete cohorts prove no closure; retain body errors before postguards/JSON.
- Pipe tests write across post-admission ticks; same-jiffy misses drift. Preserve regular-file full9/both FD flags.
