# Security I/O and custody

- Preflight HOST/entry/schema/types/roles/APIs/counts/modes/bounds/DAG.
  Pin filenames/status/bytes/SHA. Preserve limits/siblings/driver __file__,
  globals and authenticated patch/signer bytes. Bound output before accumulation;
  GNU patch before CI.
- Root sources0644, receipts0600/0644, buildsUID10001, private controls0600.
  Preserve borrowed owners/modes/umask; fchmod only qualified new owned FDs.
  Test umask077/UID/GID. Bind SSH stdin after NONBLOCK; catch restored drift.
  Host ownership needs the real Host namespace: sandbox stat maps10001 to65534;
  that view never proves owner drift or justifies chmod/chown.
- Keep bounded RAM responses through closure. Bind original stream writer
  full9/bytes/hash before selector/pipe close; guard retained reader across writer
  close. Publish immutable bytes afterward; identical bytes never permit inode
  or metadata replacement. Full9 ns use Python integers/raw JSON, never JS Number.
- Pipe/FIFO times are observations: bind original dev/inode/mode/uid/gid/nlink/
  size, flags, stream length/hash/EOF. Full9 remains strict. Bind actual cursor
  after legitimate producer/child reads: dup sharesOFD. Never assume0/EOF or
  seek-reset. Pipe tests cross ticks; same-jiffy tests miss drift.
- Finality needs original closes/names, not JSON/time. Keep body and finalizer
  errors; finalizer first. All guards/hashes fit original clocks. LIFO fullguards
  precede Output closure; test publication/body/teardown failures.
- Test acquisition/registration prefixes, FD/flag drift, same-inode offset0
  reopen, restored drift, no-op close and non-EBADF final-stat. Latch checks,
  close-entry and close errors across check/named; never retry uncertain numeric
  FDs. Prove EBADF or retain HELD. Fixture disposal proves no failed finality.
- Lock custody requires original OFD and current own-lock proof; re-locking can
  conceal loss. Retain original receivers, FD aliases and witness/metadata
  registries; mutable aliases cannot prove FD absence. Deduplicate reads, never
  bindings. Incomplete cohorts prove no closure; keep primary before guards/JSON.
- Seal Source from clean Main/registered checkout with branch checks and host
  interpreter; full9 excludes atime/whole stat_result. Fresh verifier packets,
  separate author/Root receipts; frozen QA metadata unchanged. Reader.raw_binding
  needs explicit pin or guarded hash; test real admission before payload/spawn.
- Persist bounded intent/public refusal/trace, never private stdout/locals.
  Lost output is UNKNOWN and grants no closure/retry.
- Genuine Go list selected JSON omits zero fields: require identities/closed keys/
  strict present types; default only omitted documented zeros. Authentic217-package
  regression, exact locks/import closure; never fabricate full-key wire.
- Default getattr hides declared AttributeError: finality is clean only absent or
  exactly False. Declared/getter/unknown failures stay failed. Test actual producer
  through safe refusal-envelope projection; preserving primary alone is insufficient.
