## تصمیم‌های سراسری

### Keep

- نام حساب جاری برای جلوگیری از اقدام روی حساب اشتباه؛
- یک کنترل اعلان و، فقط در صورت وجود مورد خوانده‌نشده، یک نشان unread؛
- بالاترین موضوع واقعاً نیازمند توجه؛
- یک اقدام بعدی واقعی؛
- navigation مجاز؛
- وضعیت اتصال فقط هنگام اختلال؛
- slot قفل‌شده ورود بازار برای کاربر واجد شرایط.

### On demand یا مقصد canonical

- معاملات امروز؛
- فهرست همکاران و جست‌وجوی آن؛
- کالاها و aliasها؛
- اتصال تلگرام؛
- خروج، جزئیات حساب و نقش؛
- تاریخچه، log و metadata امنیتی.

### Remove

- greeting تزئینی؛
- «حساب فعال» و «آماده انجام عملیات روزانه»؛
- summary هدر و badgeهای تکراری account/market/trades؛
- تعداد معاملات، اعلان‌ها، همکاران، کالاها و aliasها بدون اقدام وابسته؛
- empty card بزرگ برای صفر معامله؛
- role chip، route، backend source و توضیح علت permission؛
- کارت، divider، icon یا متن صرفاً برای پرکردن فضای خالی.

## نتیجه فعلی

هدف نهایی ۱۰ قاب، صفر واحد پیش‌فرض بی‌توجیه است. working draft فعلی Figma هنوز subtitle تکراری «حساب جاری» و interior غیرمجاز market slot دارد و تا اصلاح آن‌ها این audit پاس نهایی نیست. harness مشتق‌شده باید target اصلاح‌شده را نشان دهد، اما جای اصلاح خود Figma را نمی‌گیرد.
