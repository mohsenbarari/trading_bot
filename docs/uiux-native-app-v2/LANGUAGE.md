# زبان بومی Native App Feel V2

هدف این سند این است که «نزدیک به اپ iOS/Android» دیگر سلیقه‌ای نباشد.
هر سطح داخل برنامه باید همین قرارداد را پاس کند.

مرجع اصلی ظاهر: تنظیمات iOS و فهرست Material Android.
مرجع پیام‌رسان: Messages iOS و Telegram.
مرجع متن‌باز فقط برای الگو، نه کپی قالب:

- Ionic در حالت iOS
- Framework7 با پوستهٔ iOS
- راهنمای انسانی Apple برای List / Navigation / Bars
- Material 3 برای List / Navigation bar

Figma تاریخی `z8jgJxST4O2APzWnlyP9gv` دست‌نخورده می‌ماند.
صفحهٔ جدید زبان V2 در همان فایل، فقط در فاز ۱ ساخته می‌شود.

## یک زبان، نه دو کاتالوگ

- توکن محصول فقط `--ds-*`
- CSS جدید `--ui-v2-*` یا `data-ui-system` نمی‌آورد مگر فایل واقعاً کاتالوگ V2 باشد
- فیلد ورود از `--ds-control-*` یا `AppInput` / `AppSelect` / `AppTextarea` / `AppSearchField` / `AppFormField`
- فهرست از `AppInsetGroup` + `AppListItem` در حالت grouped
- دکمه از `AppButton`؛ متن داخل کادر می‌ماند

## هندسهٔ صفحه

1. پس‌زمینهٔ صفحه `#f2f2f7` یعنی `--ds-native-grouped-bg`
2. حاشیهٔ افقی صفحه ۱۶ پیکسل؛ در عرض کمتر از ۵۲۰ هم ۱۴ نمی‌شود
3. یک scroller مالک در هر مسیر
4. عنوان بزرگ صفحه دیده می‌شود؛ `sr-only` برای عنوان اصلی ممنوع است مگر صفحهٔ immersive پیام‌رسان
5. safe-area بالا و پایین محتوا را نمی‌پوشاند
6. CTA نهایی بعد از اسکرول کامل بالاتر از BottomNav است
7. overflow افقی صفر؛ زوم ۲۰۰٪ هم صفحه را پهن نمی‌کند

## فهرست inset grouped

الگوی تنظیمات iOS برای خانهٔ غیر بازار، حساب، عملیات، مدیریت و تنظیمات:

- گروه سفید با شعاع ۱۰ تا ۱۲ پیکسل
- گروه از لبهٔ صفحه ۱۶ پیکسل فاصله دارد؛ به گوشه نمی‌چسبد
- ردیف‌ها کارت جدا نیستند: بدون border و بدون radius جدا
- جداکننده hairline بین ردیف‌ها
- ارتفاع لمسی حداقل ۴۸ پیکسل
- hover lift و `translateY` روی ردیف ممنوع است
- disclosure با شورون چپ در RTL
- برچسب بخش کوتاه است، مثل «پروفایل» یا «دعوت‌های باز»؛ پاراگراف توضیح بالای گروه نیست

`AppListItem` پیش‌فرض grouped است: بدون border جدا و بدون hover lift.
حالت card فقط برای موارد نادر و صریح.

## دکمه و اقدام

- هدف لمسی ۴۸ پیکسل
- `white-space: nowrap` روی دکمهٔ تمام‌عرض یا ردیف شلوغ ممنوع است
- متن فارسی می‌شکند یا به منوی overflow می‌رود
- در کارت دعوت یا نشست، بیش از یک اقدام اصلی دیده نمی‌شود
- اقدام‌های فرعی «کپی تلگرام / کپی وب / لغو» داخل منو یا sheet هستند
- دکمه به لبهٔ صفحه نمی‌چسبد مگر CTA پایین صفحه با padding ۱۶

## متن و سادگی

قانون بودجهٔ متن:

- هر صفحه حداکثر یک خط زمینه، آن هم فقط اگر بدون آن اقدام اشتباه شود
- عنوان بخش تکرار عنوان صفحه نیست
- `AppListItem.description` وقتی عنوان کافی است حذف می‌شود
- `HelpPopover` از سطح محصول خارج است
- loading یعنی «در حال بارگذاری…» نه توضیح فنی ساختار
- confirm حداکثر دو جمله؛ جزئیات قانونی داخل گام بعدی sheet است
- رنگ و آیکون وضعیت را می‌گویند؛ پاراگراف راهنما تکرار نمی‌کند

## پوسته و ناوبری

- BottomNav ثابت برای مسیرهای روزانه؛ حس Tab Bar iOS
- FAB همبرگری فقط جایی مجاز است که تب پایین عمداً جمع شده باشد (بازار)
- پیام‌رسان immersive است: بدون FAB ناوبری سراسری
- FAB «گفتگوی جدید» حداکثر یکی است، ۴۸ پیکسل، با فاصله از safe-area
- برگشت مرورگر و دکمهٔ برگشت یک رفتار دارند
- منوی هویت خانه sheet بومی است، نه پنل وب

## پیام‌رسان

- لیست گفتگو full-bleed با جداکننده hairline؛ کارت گرد inset نیست
- اتاق full-bleed؛ composer پایین `safe-area-inset-bottom` دارد
- هدر شیشه‌ای مجاز است
- loading ردیف shimmer است، نه کارت شیشه‌ای تزئینی
- رفتار، schema، websocket، آلبوم و rollout legacy عوض نمی‌شود

## حالت‌ها

loading / empty / error / retry / offline / stale از یک ریشهٔ `App*` می‌آیند.
رنگ بخش (`tone="primary"` روی کارت) برای گروه تنظیمات ممنوع است؛ رنگ فقط برای badge و وضعیت است.

## دسترسی

- WCAG 2.2 AA
- کنتراست متن ۴.۵:۱ و فوکوس ۳:۱
- keyboard، Escape، reduced-motion
- کنترل بی‌نام یا تو‌در‌تو صفر
